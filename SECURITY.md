# Seguridad / Security

Si encontrás una vulnerabilidad, **no la publiques en un issue**: usá "Report a vulnerability" en la pestaña *Security* del repo de GitHub (o contactá a quien mantiene el proyecto).

If you find a vulnerability, please report it privately through the repository's *Security* tab instead of a public issue.

Recordatorio para quien hospeda: tu `YOUTUBE_API_KEY` y tus `SEARCH_ACCESS_CODES` son secretos. Van en variables de entorno o en `.env` (ignorado por Git), nunca en el código.
